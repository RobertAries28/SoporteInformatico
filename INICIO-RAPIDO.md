# 🚀 INICIO RÁPIDO - TechAssist 24/7

## ⚡ 3 PASOS PARA VER TU SITIO

### 1️⃣ Instalar Dependencias
```bash
npm install
```
**Esto instala React, Vite, TailwindCSS y todas las librerías necesarias.**

---

### 2️⃣ Ejecutar en Desarrollo
```bash
npm run dev
```
**Se abrirá automáticamente en:** `http://localhost:5173`

---

### 3️⃣ Publicar GRATIS en Internet

#### Opción A: Vercel (La más fácil)

```bash
# Instalar Vercel CLI
npm install -g vercel

# Login
vercel login

# Deploy
vercel --prod
```

**¡Listo! Te dará una URL como:** `https://techassist247.vercel.app`

#### Opción B: Netlify

1. Ir a: https://app.netlify.com/drop
2. Ejecutar: `npm run build`
3. Arrastrar carpeta `dist/` al navegador
4. ¡Listo!

## ❓ ¿PROBLEMAS?

### No se instala
```bash
npm cache clean --force
npm install
```

### No funciona npm run dev
Verifica que tengas Node.js instalado:
```bash
node --version
```
Debe ser v16 o superior.
